### Card 1 — Hook / Title

- **Headline (대형)**:
  ```
  리뷰는 후기가 아니라
  운영 데이터입니다
  ```
- **Body (중형, headline 아래)**:
  ```
  인디뷰티 브랜드 운영자를 위한
  리뷰 해석 노트
  ```
- **Visual note**:
  - Headline 두 줄 가운데 정렬, 줄바꿈 위치 고정 ("후기가 아니라" / "운영 데이터입니다").
  - Body는 서브헤딩 톤(작고 회색).
  - 좌측 상단 또는 본문 위에 작은 marker `Note 001` (시리즈성 표기).
  - 좌측 하단에 small caps `INDIE BEAUTY · VOC NOTE` 한 줄.
- **Max text length guidance**:
  - Headline: ≤ 22 한글 자모 합산 기준 (현재 17자 / 17자 — OK).
  - Body sub: ≤ 30자 / 줄 (현재 22자 / 14자 — OK).
  - Card 1은 본문이 길어지면 hook 효과가 떨어진다. 위 길이 이내로 유지.

- **Headline (소형)**:
  ```

  ```


  - Headline: ≤ 30자 / 줄 (현재 17자 / 18자).
  - Body: ≤ 160자 (현재 약 125자).
  - DM/이메일 줄은 short bullet 형태 유지 (CTA 시각 정렬).

## 3. Caption draft

> **톤 가이드**: 게시물 본문(카드)과 톤이 같은 분석가 보이스. 캡션은 카드를
> 압축한 요약이 아니라, 카드의 thesis를 한 번 더 다른 각도로 lock하는
> 보조 surface로 작성. CTA는 마지막 단락에 한 번만.

```
리뷰는 후기가 아니라 운영 데이터입니다.

별점만 보는 단계에서, 매주 관리하는 단계로 넘어가는
인디뷰티 브랜드를 위한 노트.

리뷰는 한 줄로 보면 평가지만,
누적되는 고객 언어로 보면 옵션/상세페이지/CS의 운영 신호가
됩니다.

같은 표현이 반복된다는 건
같은 신호가 매주 들어오고 있다는 뜻입니다.

우리는 그 반복되는 리뷰 표현을
"이건 문제다"가 아니라
"이걸 다음 한 주에 확인해볼 후보다"로 번역합니다.

리뷰 분석의 목적은 범인을 찾는 것이 아니라,
다음 한 주의 검토 우선순위를 정하는 것입니다.

샘플 리포트 / 월간 리뷰 자산 관리 문의는 DM으로 보내주세요.
(비공개 1:1 회신)
```

**Caption 길이**: 약 8개 단락, 모두 짧은 호흡으로 통일. Instagram 캡션 모바일
가독 한계(약 3~4줄에서 "더 보기"가 잘림) 고려해 첫 두 단락에 핵심 메시지를
배치.

**CTA 표현 규칙**:
- "무료"라는 단어를 1차 CTA로 쓰지 않는다 — 분석가 톤과 충돌, 가격 anchor를
  망가뜨림.
- "DM"이라는 channel 명만 노출하고, "지금 신청하면", "선착순", "무료 분석"
  같은 마케팅 어휘 금지.
- "비공개 1:1 회신"이라는 신뢰 담보 표현은 유지(브랜드 측 데이터 보호 시그널).

## 5. Publishing safety check

게시 전 모든 항목 ✅ 필수. 하나라도 ❌이면 게시 보류 + 본문 재수정.

|---|---|---|---|
| 1 | brand 이름 노출 | 카드/캡션/해시태그 어디에도 식별 가능한 브랜드명 없음 | ☐ |
| 2 | product 이름 노출 | 동일 | ☐ |

| 4 | scraped 데이터 출처 언급 | "OliveYoung에서", "Coupang에서" 등 플랫폼명/스크랩 출처 표현 없음 | ☐ |

| 6 | 제품 비판 | "이 제품은 OO이다" 형태의 단정 평가 없음 | ☐ |
| 7 | 미검증 수치 클레임 | "리뷰의 70%가…", "10배 더 정확한…", "N건의 누적" 등 출처 불명/검증 불가 수치 없음. 본 게시물은 수치 비유(예: "N줄") 자체를 사용하지 않으며, "반복되는 리뷰 표현 / 누적되는 고객 언어"로 표현 통일됨 | ☐ |
| 8 | 단정형 어휘 | "필요", "해야 함", "원인은", "결함" 등 directive 어휘 없음 (카드 6 자체 검증) | ☐ |
| 9 | 의학적 효능 단정 | "치료", "완치", "의학적", "흡수율 N%" 등 표현 없음 | ☐ |
| 10 | CTA B2B 정렬 | CTA가 정확히 "샘플 리포트 / 월간 리뷰 자산 관리 문의는 DM으로 보내주세요." 형식으로 표현되었고, "무료/지금 신청/선착순/이벤트" 등 마케팅·소비자 후킹 어휘 없음 | ☐ |
| 11 | placeholder 잔존 | `@account`, `hello@xxx`가 실 핸들로 교체되었음 | ☐ |
| 12 | 시각 자산 누설 | 어떤 카드에도 브랜드 로고/제품 사진/스크린샷/캡처 없음 | ☐ |
| 13 | hashtag 정책 | 8~12개 / B2B 영역 / 금지 태그(§4) 미포함 | ☐ |
| 14 | 2-eye review | 작성자 1명 + 검토자 1명의 사인 (이름/날짜) | ☐ |

**검사 통과 후 기록**:

## 6. Notes for future automation

이 문서는 **수동 작성 artifact**다. 첫 20개 `public_education` 게시물을
사람이 만든 뒤, 반복 패턴을 추출해 `cardnews/public_education_planner`의
template로 굳히는 것이 §10 Phase B 작업이다. 본 게시물에서 **template으로
승격 가능한 슬롯** vs **사람이 매번 검토해야 하는 슬롯**을 미리 표시한다.

### Template 가능 (반복 가능, 자동 생성 후보)

| Card slot | Template field | 비고 |
|---|---|---|
| 모든 카드의 visual baseline | `visual_style: { bg, font_family, page_indicator, accent_card_index }` | 본 시리즈 통틀어 동일 |
| Card 1 hook 구조 | `hook_two_lines: [str, str]` + `subtitle: str` | 두 줄 줄바꿈 고정 패턴 |
| Card 2~3 의 "표면 → 우리 관점" 대비 | `framing_pair: { surface_view: str, operator_view: str }` | 모든 manifesto-style 게시물의 반복 구조 |
| Card 7 CTA 블록 | `cta: { headline_two_lines, body_lines, dm_handle, email_handle, trust_line }` | DM/email handle은 환경변수에서 주입 |
| Hashtag set | `hashtag_set_id: "b2b_voc_v1"` | 정책 태그 묶음을 ID로 호출 |
| Placeholder 자동 검출 | `@account`, `hello@xxx` 등 placeholder regex로 자동 차단 | safety_validator로 코드화 |

### 사람 필수 (template로 굳히면 안 되는 슬롯)

| Card slot | 이유 |
|---|---|
| Card 4~5의 인용 표현 ("색이 달라요" 등) | 매 게시물마다 카테고리별로 다르며, 일반 표현인지 특정 brand에서 새어 나오는지 사람의 판단 필요 |
| Card 6 thesis 한 문장 | 게시물의 핵심 운영 메시지. template이 만들면 톤이 균일해져 "분석가" 보이스가 죽는다 |
| Caption 마지막 단락 직전의 thesis 재진술 | 동일 |
| Pillar 매핑 | 자동화 가능하지만 검토자가 강제 확인. 한 게시물이 두 pillar를 동시에 수행할 때의 균형 결정은 사람 판단 |
| 2-eye review sign-off | 자동화 절대 불가. 사람의 명시적 사인 필요 |

### Phase B planner 설계 시사점

- `public_education_planner`는 **항상 "수동 시드 → 자동 확장"** 모드로
  설계한다. zero-shot 자동 생성을 default로 두지 않는다.
- 입력 형태 후보:
  - `public_education_seed.yaml` (수동 작성한 카드 본문 + 정책 태그)
  - 또는 본 markdown 형식 그대로 파싱
- 출력 형태:
  - `cardnews/templates/public_education/*.html.j2`로 렌더링
  - 게시 직전 `safety_validator(public_education_mode)` 통과 강제
- 자동화 진입 조건 (§10 manual-first 게이트):
  - 첫 20개 수동 게시물의 톤/safety/CTA 검증 결과가 본 문서 같은 형태로
    archive되어 있어야 함
  - 검증 결과가 "0건의 정책 위반"으로 기록되어야 함
  - 그 이전에는 본 markdown 형식으로 100% 수동 작성 유지

## 7. Review ledger

> 발행 전 작성자/검토자 사인을 받아 lock한다. 발행 후 결과 필드(아래)는

### 7.1 Pre-publish sign-off

| Field | Value |
|---|---|
| `draft_version` | v0.2 (post-refinement) |
| `author` | (이름) — 작성일: YYYY-MM-DD |
| `reviewer` | (이름) — 사인일: YYYY-MM-DD |
| `safety_check_passed` | ☐ Yes (§5의 14항목 전부 ✅) / ☐ No (재수정 필요) |
| `placeholders_replaced` | ☐ `@account` 실 핸들로 교체 / ☐ `hello@xxx` 실 이메일로 교체 |

| `visual_mockup_reviewed_by` | (이름) — 사인일: YYYY-MM-DD |
| `dm_response_script_ready` | ☐ Yes / ☐ No (해당 doc 경로) |

### 7.4 Operational notes (발행 전 기억할 것)

- 본 게시물은 **계정의 첫 게시물**이다. 후속 게시물의 톤·길이·visual
  template 기준점이 되므로, 세부 디테일(폰트 크기, 줄바꿈 위치, 페이지
  인디케이터 위치)은 발행 전 visual mock-up으로 한 번 더 lock한다.
- 본 게시물 발행 → DM 유입 → 비공개 샘플 리포트 발송이 같은 주에 이뤄져야
  funnel 학습이 가능하다. DM 응대 스크립트(`docs/instagram_voc_publishing_
  checklist.md` 또는 별도 doc)가 발행 시점에 준비되어 있어야 한다.
- §5 안전 체크에서 한 항목이라도 ❌이면 발행 보류. 우회 발행 금지.
