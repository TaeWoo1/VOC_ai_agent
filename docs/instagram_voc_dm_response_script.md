# Instagram DM 응답 스크립트 — `public_education` funnel

> **Reusable runbook**. 공개 `public_education` 게시물(예: `648b728`
> Post 001)을 보고 DM을 보낸 인디뷰티 브랜드 운영자에 대한 1:1 응답
> 가이드. 모든 응답은 비공개 1:1 채널에서만 일어나며, 공개 surface(피드,
> Story 답글, 댓글)에는 절대 동일 내용을 게시하지 않는다.
>
> **Policy sources** (binding):
> - `docs/instagram_voc_brand_strategy.md` — `108888e` (브랜드 포지셔닝, §3 채널 분리)
> - `docs/instagram_public_education_post_001.md` — `648b728` (첫 manifesto + CTA wording)
> - `docs/instagram_voc_publishing_checklist.md` — `6dc8a0f` (§5 CTA policy + §4 language guidance)
> - `cardnews/safety_validator.py::validate_cardnews_mode` — `a2b2ae6`
>   (private_demo는 SNS 공개 불가 — DM 첨부조차 1:1 비공개)
>
> **Script version**: v1.0 (2026-05-06)

---

## 1. Scope

### Applies to

- ✅ Instagram inbound DM **from indie beauty brand operators**
  (제품 / 상세페이지 / CS / 마케팅 의사결정자, 즉 B2B 잠재 고객)
- ✅ 본 응답 스크립트로 처리한 대화는 ledger에 기록한다 (§8 conversion path).
- ✅ Story 답장, post 댓글에서 DM으로 유도된 대화도 동일 적용.

### Does NOT apply to

- ❌ **소비자 제품 문의** ("이 쿠션 어디서 사요?", "이 색이 저한테 맞을까요?").
  Template **E**(§5)로 부드럽게 redirect — 우리는 추천 매체가 아니다.
- ❌ **다른 브랜드의 공개 분석 요청** ("XX 브랜드 어떻게 보세요?", "OO 브랜드
  리뷰 분석해주세요"). 동의 없는 무동의 브랜드 분석은 §6 boundary
  language 그대로 거절.
- ❌ **광고 / 협찬 / affiliate 제안.** 본 채널은 affiliate 모델이 아니다 —
  전략 문서 §3D 참조. 짧게 거절 + 채널 정체성 한 줄.

### 응답 시작 전 필수 체크 (3초 게이트)

```
이 DM은:
├── 브랜드 운영자의 분석/리포트 문의           → 본 스크립트 §3~§5로 응답.
├── 소비자의 제품/사용법 질문                 → §5 Template E.
├── 다른 브랜드에 대한 무동의 분석 요청       → §6 boundary 그대로 거절 + 종료.
├── 광고/협찬/affiliate 제안                  → 짧게 거절 + 채널 정체성 한 줄.
└── 모호 / 분류 어려움                        → §3 first response로 시작 + 분류 질문 추가.
```

## 2. Core response principles

| 원칙 | 무엇을 의미하는가 |
|---|---|
| **Private 1:1 reply only** | 공개 댓글/Story 답장에 같은 내용 노출 금지. 답변은 모두 DM 안에서. |
| **무동의 브랜드 분석 금지** | "공개 게시물에서는 특정 브랜드를 분석하지 않습니다." 잠재 고객 본인의 브랜드도 그들의 명시적 의뢰 전까지 분석 결과를 보내지 않는다. |
| **Sample report는 관측 가능한 일부 리뷰 기준** | 공개 채널의 공개 리뷰만 사용. 표본·기간·정렬 커버리지 한계를 응답 내에서 명시. |
| **Full operational analysis는 브랜드 데이터 필요** | 셀러센터 export, API, CSV, CS 로그, 자체 보유 mall 리뷰. 데이터 제공 없이 운영 의사결정 수준의 결론은 만들지 않는다. |
| **분석가 톤 lock** | "단정하지 않지만 실무적으로 유용한 분석가." "범인을 찾는 것이 아니라 검토 우선순위를 정한다." |
| **"무료 분석" 금지** | 가격 anchor + 분석가 톤을 모두 깬다. 1차 framing은 "샘플 리포트". 비용 질문이 들어왔을 때만 §5 Template C로 별도 응답. |
| **공개 case study는 명시 동의 후에만** | DM 단계에서는 절대 약속하지 않는다. 동의서 (`consented_case_study` mode) 경로는 별도 트랙. |
| **데이터 보호 한계 솔직히 표시** | 현재 보유한 보안/저장 capability 이상으로 약속하지 않는다 (§7). |

## 3. First response template

**Trigger**: "샘플 리포트 문의드립니다", "리포트 받아볼 수 있나요?",
"DM 주신 대로 문의드려요" 류의 첫 인바운드.

```
안녕하세요, 문의 주셔서 감사합니다.

저희는 공개 리뷰 데이터를 인디뷰티 브랜드 운영(상세페이지·CS·재구매)
관점에서 해석하는 작업을 하고 있습니다.

샘플 리포트는 비공개 1:1로만 전달드리며, 공개 게시물에서는 특정
브랜드를 분석하지 않습니다.

작업을 시작하기 전 몇 가지 확인이 필요합니다:

1) 브랜드명과 분석 대상 제품(또는 카테고리)
2) 가장 보고 싶은 영역 — 상세페이지 / 제품 개선 / CS / 재구매 / 신제품 반응
3) 사내 보유 데이터 — 셀러센터 CSV / 자사몰 리뷰 / CS 로그 /
   외부 채널 공개 리뷰 링크
4) 이번에 받아보실 형태 — 샘플 리포트 1회 / 월간 리뷰 자산 관리 상담

회신은 DM 또는 이메일 중 편하신 쪽으로 가능합니다. 이메일을 알려주시면
이후 첨부·일정 잡기가 더 수월합니다.
```

**Tone notes** (검토자용):
- 첫 줄에 감사 인사 1회. 과장 없는 plain greeting.
- 두 번째 단락이 핵심: 우리가 무엇을 하는지 + B2B 정체성.
- 세 번째 단락에 §6 boundary 두 줄 즉시 lock — "비공개 1:1" + "공개에서
  특정 브랜드 분석 안 함".
- 4가지 질문은 §4 qualification 압축 버전. 4개를 넘기면 응답률이 떨어진다.
- 마지막 단락은 채널 전환 옵션. 이메일이 long-form 첨부에 더 적합하므로
  살짝 추천만 하고 강요하지 않는다.

**Length**: 약 12줄 / 350자. 모바일 DM 한 화면.

**Send window**: 평일 09:00–19:00 KST 권장. 야간/주말 인입은 다음
영업일 오전에 응답한다고 ledger에 기록.

## 4. Qualification questions

§3 first response가 4개의 질문으로 압축한 항목들의 풀버전. 답변이 모호할
때 follow-up 질문으로 사용한다. 한 번에 다 묻지 않는다 — 2~3개씩 분할.

| # | Question | Why we ask | Follow-up trigger |
|---|---|---|---|
| Q1 | **브랜드명**과 자사몰/공식 채널 URL | 공개 리뷰 sample 가능 여부 + 브랜드 식별 | 첫 응답에서 누락 시 |
| Q2 | 분석 대상 **제품 또는 카테고리** (단일 SKU 또는 라인) | sample report scope lock | 첫 응답에서 누락 시 |
| Q3 | 가장 보고 싶은 **운영 영역** — `상세페이지` / `제품 개선` / `CS` / `재구매` / `신제품 반응` 중 1~2개 | 리포트 강조 섹션 결정 | 첫 응답에서 누락 시 |
| Q4 | 사내 보유 **데이터 종류** — `셀러센터 CSV` / `API export` / `자사몰 리뷰 export` / `CS 로그` / `외부 채널 공개 리뷰 링크만` | sample 단계와 paid 단계 구분 | 첫 응답에서 누락 시 |
| Q5 | 이번 진행 형태 — `샘플 리포트 1회` / `월간 리뷰 자산 관리 상담` | conversion 단계 식별 | 첫 응답에서 누락 시 |
| Q6 | 익명/가상 case 활용 동의 여부 (Y/N) | 향후 `consented_case_study` 트랙 가능성 | sample 발송 직후 별도 confirm 단계에서 묻는 게 자연스러움 |
| Q7 | 분석 시점 **회의/의사결정 timeline** (예: 다음 주 운영회의용 / 분기 기획용) | 우선순위 + 응답 속도 산정 | sample 발송 직전 |
| Q8 | 의사결정 **참여자 수** (혼자 보는지, 팀 단위로 공유할지) | 리포트 포맷 결정 (PDF vs 발표 자료) | paid 단계 진입 직전 |

**Asking discipline**:
- DM 한 번에 3개 이상의 질문을 던지지 않는다 — 답변률이 급락한다.
- Q1~Q5는 §3 first response에 이미 포함되어 있다. follow-up은 누락된
  것만 다시 묻는다.
- Q6은 sample 발송 직후 자연스럽게 묻기 (응답이 부담스럽지 않도록).
- Q7~Q8은 sample 만족 후, paid 단계 진입 시점에 묻는다.

## 5. Follow-up templates

각 케이스 별 short template. 모두 §6 approved phrase 만 사용한다. 길이는
모바일 DM 한 화면 기준(약 8~10줄, 250자 이내).

### A. Brand provides only public product link

**Trigger**: "OO 제품 링크 보내드려요. 분석 부탁드립니다." (CSV/API 제공
없음 — 공개 리뷰만)

```
링크 감사합니다.

샘플 리포트는 해당 제품의 공개 리뷰 중 관측 가능한 일부 표본을
기준으로 작성됩니다. 정렬·기간·표본 수에 한계가 있으므로 결과는
"검토 후보" 수준으로 받아 보시면 좋을 것 같습니다.

이후 운영 의사결정 단계에서는 브랜드가 보유한 전체 데이터(셀러센터
export, 자사몰 리뷰, CS 로그)와 결합하면 신뢰도가 크게 올라갑니다.
이 부분은 샘플 리포트 회신 후 별도로 안내드리겠습니다.

샘플 리포트는 비공개 1:1로만 전달드립니다.
```

### B. Brand can provide CSV / API

**Trigger**: "CSV 제공 가능합니다." 또는 "API 권한 드릴 수 있어요."

```
공유해 주셔서 감사합니다.

CSV / 데이터 export 파일로 수신 가능합니다. 셀러센터 로그인 정보나
비밀번호는 받지 않으며, 이미 export 된 파일만 부탁드립니다.

전달 채널은 이메일 첨부 또는 보안 클라우드 링크 (만료 기한 설정)
중 편하신 쪽으로 가능합니다. 받기 전에:

1) 어떤 기간의 데이터인지 (예: 최근 6개월)
2) 어떤 채널의 데이터인지 (셀러센터 / 자사몰 / CS)
3) 개인정보 컬럼(이름·연락처·주소)이 포함되어 있는지

확인 부탁드립니다. 개인정보 컬럼이 있으면 받기 전에 마스킹 안내를
드리겠습니다.

분석 결과는 비공개 1:1로만 전달되고, 동의 없이 외부에 공유되지 않습니다.
```

### C. Brand asks "무료인가요?"

**Trigger**: "무료인가요?", "비용이 어떻게 되나요?" (비용 질문이 첫
대화에서 들어옴)

```
샘플 리포트 1회는 비용이 발생하지 않습니다. 다만 "무료 분석"으로
포지셔닝하지는 않는데, 표본·범위가 운영 의사결정에 그대로 쓰기엔
제한적이기 때문입니다. 검토 우선순위 후보를 보여드리는 단계로
이해해 주시면 좋겠습니다.

이후 월간 리뷰 자산 관리 단계는 별도 견적으로 안내드립니다. 견적은
브랜드 데이터 종류·분석 빈도·산출물 형태(PDF/회의용/대시보드)에
따라 달라지므로, 데이터 범위 확인 후 안내드리겠습니다.
```

**Tone notes**: "무료"라는 단어가 답변에 한 번 등장하지만, "무료
분석으로 포지셔닝하지 않는다"는 메타 진술이며 1차 framing이 아니다.
바로 다음 문장에서 가격 anchor를 회복한다.

### D. Brand asks "결과를 인스타에 올리실 건가요?"

**Trigger**: "이 분석을 공개 게시물로 올리시는 건가요?", "저희 브랜드
사례로 노출되나요?"

```
공개 게시물에서는 특정 브랜드를 분석하지 않습니다. 샘플 리포트는
비공개 1:1로만 전달되고, 동의 없이 어떤 형태로든 외부에 공유되지
않습니다.

만약 이후 가상/익명 사례 형태로 공개 콘텐츠에 다뤄도 괜찮은
패턴이 발견되면 별도로 동의 요청드리고, 동의해 주시는 경우에만
브랜드 식별이 제거된 형태로 사용합니다. 동의 없이는 사용하지
않습니다.
```

**Why this template exists**: 가장 자주 받는 신뢰 검증 질문. 답이
명확해야 sample 단계로 넘어갈 수 있다. 두 단락 — 첫째는 즉시 lock,
둘째는 미래 옵션 + 명시 동의 강조.

### E. Consumer asks "이 제품 추천해주세요" (DM 잘못 들어옴)

**Trigger**: 일반 소비자 톤 ("이거 사도 될까요?", "제 피부에 맞을까요?")

```
문의 감사합니다. 다만 저희는 인디뷰티 브랜드 운영자분들을 대상으로
하는 리뷰 해석 작업을 하고 있어서, 일반 소비자 대상 제품 추천이나
사용 후기 답변은 드리지 않습니다.

제품 정보는 공식 브랜드 채널이나 올리브영·쿠팡 등의 상세페이지에서
확인하시는 게 더 정확할 것 같습니다.

번거롭게 해드려 죄송합니다.
```

**Tone notes**: 차갑지 않게, 그러나 짧게. 추천 톤으로 전환되지 않도록
주의. "공식 브랜드 채널"로 redirect하는 한 줄이 핵심.

### F. Brand asks "가격이 어떻게 되나요?" (Template C와 다름 — paid 단계 진입 의향)

**Trigger**: 샘플 리포트 발송 후 또는 자료 준비된 상태에서 가격 문의.

```
가격은 다음 4가지에 따라 달라져서, 확인 후 안내드리는 게 정확합니다:

1) 분석 대상 제품 수 (1 SKU / 1 카테고리 / 라인 단위)
2) 리뷰 볼륨 (대략적인 누적 리뷰 수 또는 월 평균 신규 리뷰 수)
3) 데이터 출처 — 공개 채널 링크 / 셀러센터 CSV / API export /
   자사몰 리뷰 export / CS 로그
4) 진행 형태 — 비공개 샘플 리포트 / 단기 파일럿 / 월간 리뷰 자산 관리

진행 형태는 아래 3가지 중 하나로 시작하는 경우가 많습니다.

A) 비공개 샘플 리포트
   - 관측 가능한 일부 리뷰 또는 제공해 주신 일부 데이터를 기준으로
     scope 한정 1회 작성.
   - 유료 작업으로 진입하기 전에 결과 형태와 fit을 먼저 확인하는
     단계로 활용합니다.

B) 단기 파일럿 (보통 1 제품 또는 1 카테고리, 2~4주)
   - 샘플 리포트 → 운영 확인 질문 도출 → 후속 debrief 1회.
```

## 6. Boundary language

### Approved (use exactly)

- **"비공개 1:1로만 전달드립니다"** — 모든 응답에 최소 1회.
- **"공개 게시물에서는 특정 브랜드를 분석하지 않습니다"** — Template D
  필수, 첫 응답 권장.
- **"샘플 리포트는 관측 가능한 일부 리뷰 기준입니다"** — Template A 필수.
- **"운영 의사결정에는 브랜드가 보유한 전체 데이터가 필요합니다"** —
  Template A·B에서 sample → paid 전환을 자연스럽게 만드는 핵심 phrase.
- 보조 표현 (분석가 톤 lock):
  - "검토 후보 수준으로 받아 보시면 좋을 것 같습니다"
  - "신호일 수 있습니다" / "가능성이 있습니다" / "확인 후보"
  - "동의해 주시는 경우에만 / 동의 없이는 사용하지 않습니다"

### Avoid (절대 사용 금지)

- ❌ **"무료로 분석해드립니다"** — 가격 anchor + 분석가 톤 동시 파괴.
  Template C에서만 메타 진술로 한 번 등장 가능 (1차 framing 아님).
- ❌ **"문제점을 찾아드릴게요"** — 단정 톤 + 외부 신호로 내부 원인
  단정 불가.
- ❌ **"리뷰를 긁어서 분석했습니다"** — 스크래핑 노출. "공개 리뷰의
  관측 가능한 표본"으로 일관.
- ❌ **"인스타에 사례로 올려드릴게요"** — 무동의 공개 약속. 어떤 경우에도
  DM에서 약속하지 않는다.
- ❌ **"이 제품은 개선이 필요합니다"** — 단정형 directive.
- ❌ 보조 회피: "추천드려요", "효과가 있을 거예요", "결함이 보입니다",
  "퀄리티가 낮아요", "경쟁사 대비".

### 빠른 검수 grep (응답 발송 전)

```
(무료로 분석|문제점을 찾|긁어서|스크래핑|크롤링|인스타에 사례|개선이 필요|추천드려요|결함|퀄리티가|경쟁사 대비)
```

매치되면 즉시 발송 보류 + 재작성.

## 7. Data handling note

브랜드 데이터를 받기 전·받는 중·받은 후 행동 규칙. 이 섹션은 응답
스크립트가 아니라 **운영자 자기 검수**용이다.

### Do NOT

- ❌ **비밀번호 / 셀러센터 로그인 정보 요청 금지.** 어떤 경우에도. ID도
  마찬가지.
- ❌ **OAuth 권한 위임 요청 금지** (현재 capability 외).
- ❌ **장기 보관·재사용 약속 금지** — 현재 본 채널은 ad-hoc 분석이며
  enterprise-grade DLP capability 미보유. "받은 데이터는 분석 종료 후
  N일 내 삭제"라고 답하지 말 것 (lock된 운영 절차가 없음). 받기 전
  보관 정책을 솔직히 안내.
- ❌ **브랜드 제공 데이터의 외부 노출 금지.** 동의 없이 어떤 경우에도.
  익명/가상 사례 변환조차 동의 후에만.

### Do

- ✅ **CSV / export 파일만 받는다.** 이미 브랜드 측에서 export 한 파일.
- ✅ **수신 전 컬럼 검토 안내**: 개인정보(이름·연락처·주소·결제수단)
  컬럼 포함 여부 확인 → 포함 시 마스킹 후 재전송 요청. 본 채널이
  개인정보를 받지 않는다는 명시.
- ✅ **수신 채널은 이메일 또는 만료 기한 설정된 보안 클라우드 링크.**
  Instagram DM 첨부로 sensitive data 받지 않음 (DM 첨부는 plaintext
  보존).
- ✅ **공개 sample 사용 시 표본 한계 명시.** "관측 가능한 일부 리뷰
  기준"이라는 phrase를 sample 리포트 자체와 DM 응답에 모두 lock.
- ✅ **익명/가상 case 변환 동의는 별도 step.** sample 단계에서 묻지
  않는다. 결과 만족 후 자연스럽게 confirm.

### 운영자 솔직 표시 (DM 안에서)

데이터 보호 capability가 발전하기 전까지는 다음과 같이 답한다 (Template B
인용):

> "셀러센터 로그인 정보나 비밀번호는 받지 않으며, 이미 export 된 파일만
> 부탁드립니다."
> "분석 결과는 비공개 1:1로만 전달되고, 동의 없이 외부에 공유되지
> 않습니다."

이 두 문장 이상의 보안 약속(예: SOC2, ISO27001, 암호화 표준 명시)은
현재 운영 capability에 없으므로 **약속하지 않는다**. 잠재 고객이
SOC2/ISO27001/DPA를 요구하면 솔직히 "현재 단계에서는 그 수준의 보안
인증을 보유하고 있지 않다"고 답하고 conversion 보류 처리.

## Appendix B — Quick-fire response examples (compact reference)
