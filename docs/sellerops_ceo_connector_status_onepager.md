# SellerOps AI 판매자센터 연동 현황 요약

> 작성 기준: 2026-06-13 · 내부 개발 현황 문서 (1페이지 요약)

## 한 줄 요약

주요 판매 채널 6곳의 공식 API 연동 가능 여부를 **공식 문서 기준으로 전부
검증**했고, 실제 계정 권한이 확보되는 채널부터 **안전하게 데이터 수집을
열 수 있는 구조**를 준비해 두었습니다.

먼저 분명히 할 점: 현재는 대부분 채널이 **"연결 준비 완료"** 단계이지,
**"실제 데이터 수집 중"** 단계가 아닙니다. 이 둘의 구분이 이 문서의
핵심입니다.

- **연결 준비 완료** = 각 채널의 공식 인증 방식(열쇠 꽂는 방법)을 검증해서
  미리 구현해 둔 상태. 계정·인증키만 들어오면 다음 단계를 바로 시작할 수
  있음.
- **실제 수집 중** = 진짜 판매자 계정으로 주문·문의 등의 데이터가
  자동으로 들어오는 상태. 현재 이 단계에 도달한 채널은 없으며, 네이버가
  가장 가깝습니다(실계정 검증만 남음).

## 현재 가능한 것

- **네이버**: 주문 요약을 실제로 수집하는 로직까지 구현되어 있습니다.
  실제 판매자 계정으로 1회 검증(테스트)하는 단계만 남았습니다.
- **쿠팡 / 카페24 / G마켓·옥션 / 11번가 / SSG**: 각 채널의 공식 인증
  연결 골격까지 준비되었습니다. 인증키가 들어오면 "문 열 준비"는 끝난
  상태입니다. 단, 주문·리뷰 등 실제 데이터 수집 기능은 채널별로 다음
  단계에서 별도로 구현합니다.
- **파일 업로드**: 모든 채널에서 항상 쓸 수 있는 기본 수단으로
  유지됩니다. API가 없거나 권한이 늦어지는 채널도 파일로 데이터를 넣어
  리포트를 만들 수 있습니다.
- 특히 **리뷰 데이터는 공식 API를 제공하지 않는 채널이 대부분**이라,
  파일/리포트/수동 업로드 경로가 앞으로도 중요한 보완 수단입니다.

## 아직 아닌 것 (정직한 현황)

- 모든 채널의 주문/리뷰/문의가 자동으로 수집되는 상태가 **아닙니다**.
- 채널별로 실제 판매자 계정 권한, API 인증키 발급, 접속 IP 등록, 그리고
  데이터 형식(스키마) 확인이 먼저 필요합니다. 이 중 상당수는 판매자
  계정 보유자만 진행할 수 있는 절차입니다.
- **오늘의집**은 공식 API가 승인된 연동 솔루션 업체에만 제한 제공되어,
  직접 API 연동 대상이 아닙니다(파일 업로드로 지원).

## 채널별 현황

| 채널 | 현재 상태 | 다음 필요 작업 | 비고 |
|---|---|---|---|
| 네이버 | 주문 요약 수집 로직 구현 완료 (실계정 검증 전) | 판매자 계정·API 등록·IP 허용 후 1회 실계정 테스트 | 6개 채널 중 가장 앞선 상태 |
| 쿠팡 | 인증 골격 준비 완료 | 주문 데이터 형식 확정 → 수집 구현 | 공식 문서가 전부 공개되어 있어 다음 작업이 가장 수월 |
| 카페24 | 인증 골격 준비 완료 (토큰 자동 갱신 포함) | 쇼핑몰 운영자 동의 1회 → 주문 형식 확정 | 자사몰 채널 |
| G마켓/옥션 | 인증 골격 준비 완료 (두 마켓 통합 인증) | ESM+ 인증키 발급 → 주문 형식 확정 | 인증키 하나로 두 마켓 모두 처리 |
| 11번가 | 인증 골격 준비 완료 | 판매자 로그인 권한 확보 → 데이터 형식 확인 | **유일하게 공식 구매후기/Q&A 조회 API가 존재** (상세 규격은 판매자 로그인 필요) |
| SSG | 인증 골격 준비 완료 | 입점 계약·인증키 발급·IP 등록 → 형식 확정 | 입점 절차가 상대적으로 까다로움 |
| 오늘의집 | 직접 API 연동 불가 (공식 파트너 제한) | — | 파일 업로드로 지원 |
| 파일 업로드 | **지금 바로 사용 가능** | — | 모든 채널의 기본 fallback |

## 대표님 관점에서의 의미

- 방향은 분명합니다: **여러 판매자센터를 매일 일일이 로그인해서 확인하는
  부담을 줄이고**, 주문/문의/리뷰/정산 데이터를 **한 화면에서** 보게 하는
  것입니다. 이번 단계로 그 기반(각 채널과 안전하게 연결되는 구조)이
  완성되었습니다.
- 다만 첫 파일럿은 모든 채널을 한 번에 여는 것이 아니라, **실제 계정
  권한이 준비되는 1~2개 핵심 채널부터** 여는 것이 현실적입니다. 권한이
  준비되는 순서대로 채널을 하나씩 추가하는 구조라, 한 채널의 지연이 다른
  채널을 막지 않습니다.
- 안전 측면: 새로 만든 연동 기능은 전부 **기본 꺼짐 상태**이고, 지금까지
  실제 판매 데이터에 접근한 적이 없습니다. 켜는 것 자체가 운영자의 명시적
  결정이며, 켜더라도 채널별로 승인된 범위만 동작합니다.

## 다음 파일럿 제안 (우선순위)

1. **1순위 — 네이버 실계정 검증**: 판매자 계정과 API 등록만 되면 실제
   주문 데이터로 첫 결과를 보여줄 수 있습니다.
2. **2순위 — 쿠팡 주문 데이터 형식 확정**: 외부 권한 없이도 진행 가능한
   다음 개발 단계입니다.
3. **3순위 — 11번가 리뷰/Q&A 형식 확인**: 판매자 로그인 권한이 확보되면,
   리뷰 제품으로서 가장 의미 있는 공식 데이터 경로가 열립니다.
4. **동시 진행 — 권한 확인**: 실제 사용 중인 판매자센터별로 API 키 발급,
   권한 신청, 접속 IP 등록이 가능한지 확인을 시작해 주시면, 준비되는
   채널부터 순차적으로 연결하겠습니다.

## 아주 짧은 설명 문구 (상황별)

- **보수적 버전**: "주요 판매 채널들의 공식 연동 방식을 검증해 연결
  준비를 마쳤고, 네이버는 실계정 테스트만 남았습니다. 실제 자동 수집은
  채널별 계정 권한이 확보되는 대로 순차적으로 엽니다."
- **투자/협업 미팅 버전**: "국내 주요 판매자센터 6곳의 공식 API를 전수
  검증하고 연동 기반을 구축했습니다. 계정 권한만 들어오면 채널별로 바로
  수집을 열 수 있는 구조이고, 첫 채널(네이버)은 실데이터 검증 직전
  단계입니다."
- **제품 소개 버전**: "여러 판매자센터에 흩어진 주문·문의·리뷰를 한
  화면에서 보는 것이 목표입니다. 지금은 각 채널과 안전하게 연결되는
  기반이 완성된 단계로, 파일 업로드는 지금 바로, 채널 자동 연동은 권한이
  준비되는 채널부터 차례로 제공됩니다."
