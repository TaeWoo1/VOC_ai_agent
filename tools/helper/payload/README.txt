reviewnary 도우미 (macOS 파일럿)

무엇인가요
  reviewnary가 내 PC의 판매자센터 화면과 함께 일할 수 있게 해 주는 작은 백그라운드 프로그램입니다.
  판매자센터에 대신 로그인하거나 대신 등록하지 않습니다. 화면을 열고, 필요한 곳을 표시하고, 내가 누른 결과를 확인합니다.

설치
  1. 「reviewnary 도우미 설치.command」를 더블클릭합니다.
     - 처음 열 때 macOS가 "확인되지 않은 개발자"라고 막으면: 파일을 마우스 오른쪽 클릭 → 열기 → 열기.
       (파일럿 기간에는 담당자가 화면을 함께 보며 이 단계를 도와 드립니다.)
  2. 창이 뜨면 reviewnary 이메일과 비밀번호를 입력합니다. (이 Mac에만 저장되고 다른 곳으로 보내지 않습니다.)
  3. reviewnary 채널 연결 화면이 열립니다. [도우미 연결]을 누르고, 이 Mac에 뜨는 창에서 [허용]을 누르세요.

지원 환경
  macOS 13 이상, 이 파일과 같은 종류의 Mac (Apple Silicon / Intel 각각 별도 파일). Windows는 이 파일럿에서 지원하지 않습니다.

업데이트
  새 버전 폴더를 받아 같은 「설치.command」를 다시 실행하면 됩니다. 로그인 정보와 네이버 로그인 상태는 유지됩니다.

제거
  「reviewnary 도우미 제거.command」를 더블클릭합니다.
